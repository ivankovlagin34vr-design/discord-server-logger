# Discord Server Logger

Бот отправляет события сервера Discord в один указанный текстовый канал.

## Что записывается

- Вход и выход участников.
- Изменение никнеймов, ролей и тайм-аутов участников.
- Удаление, изменение и массовое удаление сообщений.
- Создание, удаление и изменение каналов и ролей.
- Блокировки участников и снятие блокировок.
- Создание и удаление приглашений.
- Добавление и удаление реакций.
- Создание, удаление и изменение эмодзи и стикеров.
- Создание, удаление и изменение веток обсуждений.
- Изменения запланированных событий.
- Обновление вебхуков и действия Discord AutoMod.

**Голосовые каналы не логируются:** бот не запрашивает intent `GuildVoiceStates` и не обрабатывает события входа, выхода или перемещения между голосовыми каналами.

Новые сообщения не архивируются. В журнал попадают только события изменения и удаления сообщений.

## Требования

- Node.js 20 или новее.
- Discord-бот в [Discord Developer Portal](https://discord.com/developers/applications).
- Доступ бота к серверу и каналу для логов.

## Настройка Discord

1. Создай приложение и бота в Discord Developer Portal.
2. В разделе **Bot** скопируй токен. Не публикуй его и не добавляй в GitHub.
3. Включи **Server Members Intent** и **Message Content Intent** в разделе Privileged Gateway Intents.
4. Пригласи бота на сервер с разрешениями:
   - View Channels
   - Send Messages
   - Embed Links
   - Read Message History
5. Убедись, что бот видит канал, куда должны приходить логи.

Для получения ID канала включи Developer Mode в Discord, нажми правой кнопкой по каналу и выбери **Copy Channel ID**.

## Запуск

1. Склонируй репозиторий или скачай ZIP.
2. Установи зависимости:

   ```bash
   npm install
   ```

3. Создай в корне файл `.env` по образцу `.env.example`.
4. Заполни переменные:

   - `DISCORD_BOT_TOKEN` — токен бота.
   - `LOG_CHANNEL_ID` — ID канала для всех записей.
   - `LOG_MESSAGE_CONTENT` — `true` для записи текста удалённых и изменённых сообщений, `false` чтобы скрыть содержимое.

5. Запусти:

   ```bash
   npm start
   ```

## Размещение на хостинге

- Build command: `npm install`
- Start command: `npm start`
- Runtime: Node.js 20+

Добавь переменные окружения в панели хостинга. Не загружай файл `.env` в репозиторий.

## Важные замечания

- Если `LOG_MESSAGE_CONTENT=true`, бот может записывать содержимое изменённых и удалённых сообщений. Учитывай приватность участников и правила своего сервера.
- Для получения текста сообщений включи Message Content Intent в Developer Portal.
- Некоторые события Discord могут быть недоступны, если бот не имеет нужного intent или разрешений.
- Один ID канала используется как единое место назначения. Если бот обслуживает несколько серверов, у него должен быть доступ и к исходным серверам, и к выбранному каналу логов.
